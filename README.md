# orgi.is-a.dev

Portfolio — Next.js (App Router, static export) · Tailwind v4 · GSAP · Lenis · React Three Fiber.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site → out/
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`
(repo Settings → Pages → Source must be **GitHub Actions**). `public/CNAME` keeps the custom domain.
